批量导入题目（Excel / CSV）

上传 .xlsx 或 .csv，列为：题型 | 题干 | 选项A … 选项H | 答案 | 分值 | 解析 | 知识点（知识点可留空，多个用 | 分隔）。 第一行是表头会自动跳过，没有表头也行。上传后先出预览页，确认才写入题库。

答案写法很宽松：单选可填 B、2（第几个选项）或选项原文；多选可填 ABD、A,B,D、A、B、D 或选项原文； 判断可填 A/B、正确/错误、对/错、T/F、√/×；填空多个答案用 | 分隔。 题型留空时会按选项和答案自动识别（预览页会标注）。

批量导入题目（JSON）

粘贴一个 JSON 数组，每个元素一道题，提交后先出预览页，确认才写入题库。 type 支持 choice / multi / judge / blank 及中文别名（单选 / 多选 / 判断 / 填空题…），留空会自动识别； 答案写法同 Excel（字母、序号、选项原文均可）；可用 kp 或 kps 挂知识点（填知识点名称）。

字段类型说明
type字符串 题型：choice 单选 / multi 多选 / judge 判断 / blank 填空；留空按选项和答案自动识别
question字符串 题干内容
options字符串数组 选项列表，仅单选/多选需要；按顺序对应 A、B、C、D…（判断/填空可省略，支持 "A. 选项内容" 写法）
answer字符串 正确答案：单选填字母如 "B"、序号如 "2" 或选项原文；多选填 "AC" / "A,C" / "A、C"；判断填 "A"（正确）/ "B"（错误）/ "对" / "T" 等；填空填 "答案1|答案2"（忽略大小写）
score数字 分值，可省略（默认 5）
kp / kps字符串或数组 知识点名称，可省略；名称不存在会忽略并提示

示例（支持子题）：

[
  {"type":"choice","question":"1+1=?","options":["1","2","3","4"],"answer":"B","score":5},
  {"type":"blank","question":"HTTP默认端口是____","answer":"80","score":5},
  {"type":"choice","question":"阅读程序：\n```cpp\nint x=5;\n```","answer":"B","score":2,
   "sub":[
     {"type":"judge","question":"输出为5","answer":"A","score":1},
     {"type":"choice","question":"x的类型？","options":["int","float"],"answer":"A","score":3}
   ]}
]
